# plugpage

Plug digests and page fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/plugpage/

## Install / run

```bash
git clone https://github.com/theworker02/plugpage.git
cd plugpage
node src/cli.js
node --test
```
